LOCAL-FIRST PRIVACY

Capabilities without custody.

Kyntral Cloud should not need Notes text, source URLs, media bytes, clipboard contents, or destination filenames to authorize a local workflow. The control plane handles opaque authority metadata; private workflow inputs stay on the device whenever possible.

FOR DEVELOPERS

Portable capability contracts.

Protocol schemas, conformance vectors, and the protocol-facing SDK are designed for interoperability. Capability manifests declare requirements; they never grant themselves authority.
