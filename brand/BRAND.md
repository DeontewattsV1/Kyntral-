# Kyntral brand identity

## Name

**Kyntral**  
Pronunciation: **KIN-truhl**

## Positioning

**The permission layer between AI and your devices.**

Primary tagline:

> **AI coordinates. You control.**

Developer line:

> **Permissioned AI-to-device execution.**

## Visual idea

The mark should combine:

- an abstract **K**
- a connection path
- a central authorization gate

The central node represents the user-controlled boundary between proposal and execution.

## Palette

| Token | Value | Use |
| --- | --- | --- |
| Obsidian | `#080B10` | primary dark field |
| Graphite | `#171B24` | elevated surfaces |
| Frost | `#F5F7FA` | light text/background |
| Ion | `#746BFF` | primary brand accent |
| Signal | `#76F2C5` | verified/authorized/completed |

Use mostly neutral surfaces. Signal should be scarce and semantically meaningful.

## Voice

- precise
- calm
- premium
- security-literate
- never imply unrestricted device control
- never imply Apple/OpenAI/xAI endorsement
