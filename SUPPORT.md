# Kyntral Support

Kyntral v0.1 is release-candidate software.

## General support

Use GitHub Issues for reproducible, non-sensitive bugs and feature requests:

https://github.com/DeontewattsV1/Kyntral-/issues

Include the Kyntral version/commit, iOS version or MCP client, capability/workflow identifier, expected behavior, observed behavior, and content-free error codes.

Do **not** post OAuth tokens, private keys, Notes text, source URLs, media bytes, personal files, or other private workflow content.

## Security issues

Use GitHub's private Security Advisory flow for exploitable vulnerabilities. See `SECURITY.md`.

## Personal-device onboarding

Official shared Shortcut:

https://www.icloud.com/shortcuts/effa6cac2e9b4702bed9128a8749e1f8

The Shortcut stages user-selected workflow inputs locally. Device pairing and API authorization happen separately in the Kyntral app.
